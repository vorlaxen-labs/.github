Vorlaxen Labs is an independent global organization. We turn what fascinates us into things people use. The public work is open source, mostly TypeScript and Node.js: backend tools, agent skills, and the DevOps around shipping them.

When a need is real, we get close to it. We try, revise, and keep going until people can trust the tool. How an idea sounds matters less than what it does in someone's hands. If people cannot understand it, use it, or trust it, it is not finished.

## Public work

[bar-js](https://github.com/vorlaxen-labs/bar-js) (`@vorlaxen-labs/bar-js`) builds the JSON response for Express and Fastify. No runtime dependencies. The source is also a worked example on the [XERJ Corpus Hub](https://hub.xerj.org/corpus/vorlaxen-labs--bar-js).

[huk-js](https://github.com/vorlaxen-labs/huk-js) (`@vorlaxen-labs/huk-js`) is a TypeScript utility set with nothing else bundled in. Turkish-aware slugify, validation, a bit of crypto, and storage that still works during SSR.

[agent-skills](https://github.com/vorlaxen-labs/agent-skills) (`@vorlaxen-labs/agent-skills`) installs `SKILL.md` files into Cursor, Claude Code, Copilot, Windsurf, Codex, and Gemini. The packs are in [skills-hub](https://github.com/vorlaxen-labs/skills-hub).

[scam-lens-for-discord](https://github.com/vorlaxen-labs/scam-lens-for-discord) flags scam images and bad domains in a Discord server.

[AratMicro](https://github.com/vorlaxen-labs/AratMicro) is a micromouse for Robosam and the MEB robot competition. C++, KiCad, and PlatformIO.
